### 3. **Structured Data (Schema.org JSON-LD)**
```json
{
  "@type": "Event",
  "name": "Ng Conf Perú 2026",
  "startDate": "2026-10-09",
  "endDate": "2026-10-10",
  "location": "UTEC Barranco, Lima, Perú",
  "organizer": "Comunidad Angular Perú"
}
```
- Ayuda a Google a entender que es un evento
- Aparece en Knowledge Graph y resultados enriquecidos
- Mejora el CTR (Click Through Rate)

### 4. **Archivos de Configuración**

#### `robots.txt`
- Permite indexación de páginas públicas
- Prohíbe indexación de carpetas privadas (`/_next/`, `/api/`)
- Especifica sitemaps para Google y Bing
- Optimiza crawl budget

#### `sitemap.xml`
- Lista todas las páginas importantes
- Define última modificación y frecuencia de actualización
- Incluye imágenes en el sitemap
- Prioridad de cada página establecida

#### `site.webmanifest`
- Configura PWA correctamente
- Define iconos para home screen
- Metadatos para navegadores modernos

### 5. **Layouts Específicos por Página**
Cada sección tiene metadatos únicos:
- `/agenda` - Enfoque en programa y charlas
- `/faq` - Palabras clave de búsqueda de ayuda
- `/codigo-de-conducta` - Términos de seguridad e inclusión

## 📱 Checklist para Mantener SEO

### Antes de Publicar
- [ ] Verificar título único (50-60 caracteres)
- [ ] Descripción optimizada (150-160 caracteres)
- [ ] Imágenes con atributo `alt` descriptivo
- [ ] Enlaces internos estratégicos
- [ ] Sin errores 404
- [ ] Velocidad de página > 3s (LCP < 2.5s)

### Después de Publicar
- [ ] Enviar sitemap a Google Search Console
- [ ] Verificar indexación (site:ngconf.pe)
- [ ] Monitorear posiciones en Google
- [ ] Revisar Core Web Vitals
- [ ] Actualizar metadatos según datos de búsqueda

### Mejoras Técnicas
- [ ] Habilitar compresión GZIP
- [ ] Usar CDN para imágenes estáticas
- [ ] Implementar lazy loading de imágenes
- [ ] Minificar CSS y JavaScript
- [ ] Implementar cache header correcto
